# Amr Hassan

## Systems Architect | AI-Augmented Workflows

I design **governed, AI-augmented systems** with explicit lifecycles, authority boundaries, and traceability.

My background spans over two decades in regulated environments, including pharmaceutical engineering, commissioning, qualification and validation (CQV), and large-scale project delivery. I bring that discipline to human–AI interaction and workflow design.
